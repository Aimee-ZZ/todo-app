# Flask To‑Do App (starter)

A small Flask app to manage a to‑do list with SQLite.

Run locally:
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. python app.py
Open http://127.0.0.1:5000 in your browser.

Features:
- Add tasks
- Mark complete / uncomplete
- Delete tasks

Next ideas: add user accounts, a REST API + React frontend, or deploy to Render/Heroku.
